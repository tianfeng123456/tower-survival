# 森野守卫 · Grove Guardian

Vite + Three.js 原生 ES 模块的单人 3D 生存建造小游戏。玩具风格的低多边形林地、等距跟随镜头、中文 HUD，无服务器游戏逻辑。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：

```bash
npm run build
npm run preview
```

`vite.config.js` 设置 `base: './'`，可将 `dist/` 部署到任意静态 HTTP 服务器的子目录。请通过 HTTP 打开，而不是 `file://`。

## 操作与玩法

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对屏幕方向移动 |
| 靠近树木并停留 | 绿色进度环填满后自动采集，获得 10 木材 |
| 自动战斗 | 近身自动挥剑攻击 |
| Space / 旋风斩按钮 | 范围伤害和伐木，冷却 12 秒，短暂无敌 |
| 1 / 2 / 建造栏按钮 | 选择围墙 / 箭塔 |
| E / 点击地面 | 在角色前方的全息格子建造；红色表示无效或木材不足 |
| U / 升级按钮 | 在核心 5 米范围内，消耗金币全局升级，恢复生命 |
| N / 提前迎敌 | 本波生成完毕后，提前开始下一波，可叠加存活敌人 |
| 右上角 1× | 切换 1 / 2 / 4 倍速，所有游戏计时同步加速 |
| Esc / 右上角暂停 | 暂停 / 继续；窗口失焦自动暂停 |

开始有 100 木材及两座免费箭塔。守护核心，同时保持守林人存活。敌人掉落金币，金币弹跳后靠近吸取，远处金币 5 秒后自动飞回。核心附近安全时缓慢恢复玩家和核心生命。树木 150 秒后重生。

围墙阻断 BFS 流场寻路；无法绕行时，敌人攻击封路建筑。每 4 波出现巨人，显示血条和剩余血量。全局升级将现有和未来围墙替换为石墙 / 铁门，箭塔按网格坐标奇偶升级为激光塔或火炮塔（偶数激光，奇数火炮）。铁门是坚固的阻挡建筑，和石墙使用相同碰撞规则。最高等级为 4 级。

40 波配置每波 180 秒，正常节奏约 2 小时；最后一波敌人全部消灭即胜利，核心或玩家生命归零即失败。结束界面可重新开始。

## 代码与配置

- `src/main.js`：入口与 WebGL 启动错误提示。
- `src/game.js`：固定 60Hz 模拟、可调速循环、初始化和胜负流程。
- `src/input.js`、`src/camera.js`：键盘 / 鼠标、跟随等距相机。
- `src/world.js`、`src/player.js`：场景、森林采集、玩家近战与技能。
- `src/enemies.js`：敌人、巨人、BFS 流场、空间桶分离和攻击。
- `src/buildings.js`、`src/towers.js`、`src/projectiles.js`：建造、自动索敌、箭 / 激光 / 抛物线炮弹与爆炸。
- `src/fx.js`、`src/hud.js`：金币、伤害数字、烟尘、闪光和中文界面。
- `src/waves.js`、`src/upgrades.js`：波次调度和全局升级。
- `src/data/waves.js`：40 波数量、间隔、生命、伤害、移速和巨人数量。
- `src/data/buildings.js`：格子尺寸、地图边界、建筑消耗与战斗属性。
- `src/data/upgrades.js`：升级价格、生命 / 伤害 / 射程倍率。

## 程序纹理

`public/textures/` 中包含草地、树皮、石材和核心四张 64×64 PNG。通过纯 Node.js 的 zlib 和 PNG CRC 编码生成，无原生依赖：

```bash
npm run textures
```

游戏加载失败的纹理回退为纯色材质。字体使用本机字体，不依赖外部 CDN。几何体和材质缓存复用，敌人采用空间桶分离；同时存活敌人限制约 200，超出时延迟生成，不丢失波次单位。森林采用三组 InstancedMesh 批量绘制。像素比上限 1.6。

`npm test` 使用 Node.js 内置测试验证绕墙 / 封路 / 破墙寻路、40 波生成完整性、200 敌人生成上限、最终胜利条件和 PNG 解码，不依赖 Three.js。该环境 6 项逻辑测试和所有 JavaScript 文件语法检查已通过；尚未完成浏览器实际游玩验证。

## 已知限制

- 面向桌面键盘鼠标；小屏界面会缩放，但未提供触屏移动摇杆。
- 无音频、存档、多人模式或建筑拆除功能，刷新会重新开始。
- 铁门不支持手动开关，树木可穿过，敌人不将树木计入寻路。
- 寻路采用四邻接整数格流场，密集敌群在墙角可能短暂拥挤。后期大量建筑 / 阴影性能取决于显卡。
- 40 波经济与难度为可调的初始设计，未经过完整两小时人工平衡验证。
- 已在联网环境完成 `npm install` 与 `npm run build`（构建成功，主包约 527KB，有体积警告）；无头浏览器可进入游戏并渲染。未做完整 2 小时人工试玩，建造 / 升级 / 胜负流程未在浏览器中逐项手测。

## 部署（GitHub Pages 项目站）
- `vite.config.js` 中 `base: '/tower-survival/'`，对应 https://tianfeng123456.github.io/tower-survival/ 。若改仓库名或用根域名/Cloudflare Pages，需相应改成 `'/<仓库名>/'` 或 `'/'`。
- 构建：`npm ci && npm run build`，输出目录 `dist/`（纯静态，运行时不需要 Node）。
- `public/.nojekyll` 会复制进 dist，避免 Jekyll 处理。单页无前端路由，不需要 404.html 回退。
- 发布方式：把 `dist/` 推到 `gh-pages` 分支，或用 Actions（upload-pages-artifact 上传 `dist`）。
- 本地预览：`npm run build && npx vite preview`，然后打开 http://localhost:4173/tower-survival/
- 注意：https://su-cheng-che.pages.dev 是别人的 Cloudflare Pages 站，与本项目无关。

## 手机操作
左下虚拟摇杆移动；右侧按钮：建造 / 旋风 / 升级；底部工坊切换墙/塔；右上暂停、加速。触屏点地面不会误建造。键鼠操作保持不变。
